# Titanic Survival Game：沙盒测试与成熟度审计

测试日期：2026-09-29

## 1. 当前版本定位

当前版本已经不是传统的点击答题，而是一个嵌入 Streamlit 的浏览器小游戏原型，包含两种玩法：

- **救生艇指挥官**：选择人物，将人物拖入绿色救生艇；救生艇有 4 个位置，按选择结果计分。
- **扮演乘客**：选择一个人物，沿“三等舱 → 大楼梯 → 上层甲板 → 救生艇”的路线逃生；错误路线扣除 8 秒。

它已经具备游戏循环、倒计时、容量限制、得分、排行榜和历史/模型分析入口，但还没有达到“历史模拟游戏”或“可长期运营网页游戏”的成熟度。

## 3. 目前的主要问题

### A. 游戏规则仍然是“演示规则”，不是历史模拟

人物的 `safe: true/false` 目前直接写在 `static/game.html` 中，且人物是少量虚构角色。它适合展示交互流程，但不能被解释为真实 Titanic 乘客结果，也没有模拟家庭、船员优先级、救生艇发射顺序、舱门、淹水、拥堵或阶级差异。

### B. 决策反馈不足

玩家只知道“得了多少分”，不知道为什么某个选择更好，也看不到模型概率、特征影响和历史事实之间的边界。游戏需要在结算后给出：玩家决策、模型预测、实际历史标签、差异原因和不确定性。

### C. 关卡结构还不够丰富

当前乘客模式是一条固定路线，救生艇模式是一个固定容量池。成熟版本需要关卡配置、事件系统和可重复挑战，例如：不同起始舱位、不同水位、不同可用救生艇、家属绑定、随机障碍和多种结局。

### D. 产品结构仍有原型痕迹

游戏被放在 Streamlit 分析应用中，下面还保留旧的 `Optional model quiz`。对于真正的个人主页，玩家会误以为这是一个分析仪表盘，而不是完整游戏。正式发布应将游戏作为独立前端路由，分析页面作为“幕后数据实验室”。

### E. 数据和排行榜不能支持公开运营

排行榜目前写入浏览器 `localStorage`，只在本机有效，也没有用户名校验、反作弊、服务端持久化或跨设备同步。它适合 demo，不适合网站公开排行榜。

### F. 可访问性与移动端仍需加强

点击兜底路径已经验证可用，但拖拽仍需要键盘替代方案、触屏拖拽、焦点状态、ARIA live 播报和更明确的“当前选中人物/下一目标”状态。否则部分玩家会卡在“我该拖什么到哪里”。

### G. 工程可维护性不足

- 游戏逻辑、人物数据和界面模板都集中在一个 HTML 文件中。
- 依赖版本仍偏宽松，缺少锁定文件。
- 自动化测试覆盖 Python 模型，不覆盖游戏状态机、计分边界、拖拽事件和浏览器回归。
- Streamlit 当前仍使用 `components.html`，运行时会提示未来 API 迁移问题。

## 4. 我的个人分析结果与结论

从玩家角度，这一版已经能让我理解“我在船上做决定”，而不是回答几道选择题；尤其是救生艇容量、倒计时、路线错误扣时和排行榜，形成了最基本的游戏反馈闭环。当前最成功的设计是“人物卡片 + 船舱平面 + 绿色救生艇 + 金色下一步目标”，视觉语言已经比红黄提示框清晰很多。

但从“成熟交互游戏”的标准看，我目前给它 **6/10：可玩的交互原型，而不是完成品**。最大短板不是颜色或按钮，而是规则深度和反馈解释：玩家的选择还没有真正改变船上局势，人物标签也没有可信的数据来源，因此高分暂时主要代表“理解了操作规则”，还不能代表“做出了更好的历史决策”。

我的结论是：下一阶段不应该继续堆更多按钮，而应先把游戏核心抽成一个可测试的模拟引擎，再把历史数据、模型概率和视觉界面接到这个引擎上。优先级应为：

1. 把人物、舱位、救生艇、事件、时间和结局从 HTML 中移到结构化关卡数据与状态机。
2. 增加结算报告：个人决策分析、模型解释图、历史事实、置信度和替代决策。
3. 增加至少 3 个真正不同的关卡，而不是只改变标题。
4. 将拖拽、点击、键盘和触屏输入统一到同一个动作接口，并加入浏览器 E2E 测试。
5. 最后再把游戏从 Streamlit iframe 拆成个人主页上的独立网页，并把排行榜迁移到后端。

在完成这五步之前，适合把项目称为“Titanic Survival Game Prototype”；完成之后，才适合对外称为成熟的交互式历史模拟游戏。

## 5. 独立网站迭代结果

为了修正“游戏卡在分析页面”的根本问题，新增了 [website](../website) 独立静态站点：

- 默认英文，并提供中文切换。
- 有开场动画、跳过入口、玩法教学和叙事型首页。
- 游戏区域独立于 Streamlit，可直接部署到静态托管服务。
- Vercel 临时部署已经通过浏览器验证，根地址可以显示首页和开场动画。

当前 Vercel 预览属于匿名临时部署，会在约 60 分钟后过期；正式发布仍需要登录 Vercel 并认领项目。排行榜仍是浏览器本地排行榜，不是线上多人排行榜。
